# BetterSpectate
Improves the versatility of the spectator camera.

## Info
This client-side mod aims to provide highly customizable improvements to the spectator camera.

## Features
### First Person
- Toggleable first person view<br>
- Keybinds can be set in config<br>
- This view mimics the perspective of the player being spectating<br>
### Third Person
- Customizable camera zoom using the scroll wheel<br>

## Config
Both the zoom and first person spectate features can be disabled in the config file located in `BepInEx/config/Fusition.BetterSpectate.cfg`<br>
- **Zoom Speed** changes how quickly the camera will zoom in. Note: If this is too high, zooming in or out will appear jumpy.<br>
- **Max Zoom Distance** configures the furthest point from the player that you can zoom out to.<br>
- **Min Zoom Distance** configures the closest point to the player that you can zoom in to.<br>
- **Default Zoom Distance** determines how far from the player the camera will start upon death or switching to third person view from first person.<br>
- **Default to First Person** controls the perspective that you will start in upon death.<br>
- **First Person Keybind** modifies the key that you must press to switch between perspectives.<br>
